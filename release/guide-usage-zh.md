# Tiny Container V6 使用说明（最终版，已移除键盘）

> 这一版对应你说的「键盘不写了，全部删掉，其他保留」。
> 除键盘外的所有功能都保留：自由缩放、鼠标加速、滚轮速度、指针大小/颜色、
> 缩放前确认、Windows 风格任务栏、任务管理器、截图、剪贴板历史、
> 导出容器不丢数据、一键跳开发者选项。

## 二、这一版删掉了什么

| 删掉的东西 | 说明 |
|---|---|
| 粉色悬浮键盘 `tiny_osk.py` | 容器里不再有这个程序和它的自启项 |
| 黑客键盘布局移植 `hk_layout.py` | 一并移除 |
| 打字光标位置桥 `tiny_osk_caret.py` | 一并移除 |
| 光标旁的键盘按钮 | 安卓界面里那个小键盘图标彻底没有了 |
| 三指轻点呼出键盘 | 手势选项里的「打开悬浮键盘」选项已移除，三指默认改回「无」 |
| 设置页「悬浮键盘」分类 | 两个开关都没了 |

如果你之前装过 V5，容器里已经写进去的键盘文件，**这一版第一次启动时会自动删掉**
（`applyImagePatch()` 在解压增量包之前先 `rm -rf` 那批路径），所以不会出现
「自启项还在、程序没了」的报错。

## 三、保留的功能（全部实测过配置）

### 应用内：功能设置 → 设置 AVNC → 输入

| 设置项 | 位置 | 范围 | 默认 |
|---|---|---|---|
| 鼠标加速 | 调节灵敏度下方 | 开/关 | 开 |
| 加速强度 | 鼠标加速下方（依赖它） | 1~8 倍 | 6 倍 |
| 慢速移动速度 | 同上 | 10~100% | 30% |
| 滚轮速度 | 同上 | 档位 1~9 | 3 档 |
| 缩放前确认 | 同上（「指针」分类末尾） | 开/关 | 开 |

滚轮档位对应的「手指滑多少像素 = 滚一格」：
1→12px、2→16px、**3→20px（等于官方原值）**、4→29、5→38、6→47、7→56、8→65、9→74px。
**想更慢就往右调到 9。**

### 应用内：「指针」分类

| 设置项 | 范围 | 默认 |
|---|---|---|
| 指针大小 | 50~300% | **150%** |
| 指针颜色 | 取色板（粉色排最前）+ RGB 微调 | 不启用（原色） |

指针颜色那一行右边有个开关，打开后才会用下面的颜色；关掉就是服务器原样。
配色方式是按亮度映射，所以黑底白边的指针会整体变成你选的颜色，不只是描边。

### 应用内：功能设置页

| 按钮 | 作用 |
|---|---|
| 停止限制子进程 | 一键跳到安卓「开发者选项」，打开里面的「停止限制子进程」 |

### 桌面内（镜像侧）

| 功能 | 怎么用 |
|---|---|
| Windows 风格任务栏 | 默认就是，同一程序多窗口合成一个图标 |
| 任务管理器 | `Ctrl+Shift+Esc`（已装，之前失败是因为容器里没有这个程序） |
| 截图 | `Print` 全屏 / `Alt+Print` 当前窗口 / `Shift+Print` 选区 |
| 剪贴板历史 | `Super+V` 历史 / `Super+Shift+V` 完整窗口（对齐 Windows 的 Win+V） |
| 终端 | `Ctrl+Alt+T` / 文件管理器 `Super+E` |
| 应用菜单 | `Super+R` 或 `Alt+F2` |
| 导出容器不丢数据 | 已修 `/opt/tiny/export.sh`，不再执行 `apt clean` 和删 `~/.mozilla` |

任务栏**不再预固定任何程序**（按你的要求）。想固定就右键任务栏上的图标 → Pin。

## 四、升级机制（V4 起就有，这里说明清楚）

APK 里带了三个文件：

| 文件 | 作用 |
|---|---|
| `assets/rootfs.tar.zst` | 完整系统镜像（732,826,915 字节），全新安装时用 |
| `assets/rootfs.patch.tar.zst` | 增量包（546,965 字节，262 个文件），覆盖到已有容器上 |
| `assets/rootfs.stamp` | 版本戳 `v6-2c671cf642cd8313` |

启动时比较戳记，不一致就**静默**打增量补丁，不弹对话框、不动你的个人文件。
只在换了镜像之后才会重跑一次。

## 五、安装后怎么验证（9 步）

1. 覆盖安装 V6，打开 App，进 Linux。
2. 桌面底部任务栏应该是**分组图标 + 可以 Pin** 的样子（不是老式的窗口条）。
3. 按 `Ctrl+Shift+Esc`，任务管理器应该直接弹出来（不再报「没有那个文件或目录」）。
4. 按 `Print`，截图工具应该出现。
5. 按 `Super+V`，剪贴板历史应该出现。
6. 点「功能设置 → 设置 AVNC → 输入」，**应该能正常进入设置页**（这是 V4 修的崩溃）。
7. 往下滑，能看到「鼠标加速 / 加速强度 / 慢速移动速度 / 滚轮速度 / 缩放前确认」。
8. 双指缩放一次：应该只在屏幕中间出现「再缩放一次以确认」的提示，第二次才真的缩放。
9. 指针颜色开关打开、选个粉色，指针整体变成粉色。

## 六、如果你发现不对

请把这三样发我：

1. 哪个界面、点了什么、期望什么、实际什么。
2. 如果是桌面内的功能，容器终端里跑一下并把输出贴出来：
   ```bash
   xfce4-panel --version
   dpkg -l | grep -E "docklike|taskmanager|clipman|screenshooter"
   ```
3. 如果是 App 崩溃，设置里开「开发者选项 → 错误报告」，或者直接把崩溃的时间点告我。

- 镜像里的东西没生效：先确认 `assets/rootfs.stamp` 的版本和 App 里记的一致，
  或者干脆在「功能设置」里手动重装一次容器（会清空容器数据）。
- 想回退：见 `apks-archive-keep-forever/readme-versions-zh.md`，V1~V6 全在。
