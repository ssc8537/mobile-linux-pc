refactor(tools): 补丁脚本改为自动查找工作区根，不再写死绝对路径

26 个 tools/patch 脚本原本在文件头写死
  C:\Users\Administrator\Desktop\1-test\1-linux-小小容器\...
换机器 / 换目录就无法运行。现在统一为：

  def _find_ws():
      env = os.environ.get('TC_ROOT')       # 手动指定优先
      ...
      从脚本目录向上找含 build-env-toolchain 或 source/app 的目录

  WS = _find_ws()
  PATCH_DIR = os.path.dirname(os.path.abspath(__file__))

各脚本原来的 ROOT / RES / J / base 等变量改为
os.path.join(WS, 'avnc-upstream-fork-deletable', 'app', 'src', 'main', ...)。
